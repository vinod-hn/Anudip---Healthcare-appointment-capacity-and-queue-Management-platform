# UI Guidelines

Use the shared variables in `frontend/css/global.css`; do not introduce a screen-specific palette. The primary blue is `#2563EB`, teal is `#0D9488`, success green is `#16A34A`, navy is `#123047`, and the page background is `#F3F8FA`.

Use Inter with an Arial fallback, 10px card radius, 8px button radius, 16–20px card padding, visible keyboard focus, and text labels on every status badge. Patient pages use the white horizontal navbar. Staff pages use the shared navy sidebar.
