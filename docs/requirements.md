# Healthcare+ Requirements

Sprint 1 is a frontend-only prototype for healthcare appointment capacity and queue management. It uses fictional data in the browser and does not include a backend, API, database, authentication, or real-time service.

## Screens

1. Patient home / find a doctor
2. Doctor details and availability
3. Patient appointment booking
4. Booking confirmation
5. Admin dashboard
6. Appointment management
7. Doctor management
8. Schedule / capacity management
9. Receptionist patient check-in
10. Live queue management

All screens should remain connected through relative links and the shared `HealthcareState` object.
